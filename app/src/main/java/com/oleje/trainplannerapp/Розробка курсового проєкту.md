**1\. Алгоритм пошуку маршруту (Пункт 4: Персональний план)** Ти згадав задачу комівояжера (TSP) та *A*∗. Тут важливо не переплутати:

### **1\. Модифікований алгоритм Дейкстри (Time-Dependent Dijkstra) \+ Топ-3 маршрути \+ Жадібні знижки**

У класичному алгоритмі Дейкстри вага ребра статична (просто відстань між містами). У залізничній мережі між двома станціями є **кілька ребер** (різні рейси в різний час), а також з’являється **умова часу пересадки**.

#### **Чому звичайний Дейкстра не підійде і як працює модифікація:**

> 1. **Представлення графа:**  
   * **Вершина (Station):** місто/станція (наприклад, Львів, Жмеринка, Одеса).  
   * **Ребро (RouteEdge / TravelTicket):** конкретний рейс, який має: fromStation, toStation, departureTime (хвилини від початку доби або LocalDateTime), duration (тривалість), basePrice (базова ціна), transportType (приміський, Інтерсіті, купе).  
> 2. **Умова переходу (часове вікно):** Якщо ми прибули на проміжну станцію о currentTime, ми можемо сісти на наступний потяг тільки тоді, коли:  
>    nextTrain.departureTime≥currentTime+15 хв (мінімальний час на пересадку)  
> 3. **Критерій оптимізації (Вага шляху):**  
   * **Для пільговиків (або режиму «Найшвидший»):** мінімізуємо загальний час у дорозі (час прибуття в кінцеву точку мінус час старту). При цьому, якщо transportType \== SUBURBAN (приміський), його ціна для пільговика автоматично стає 0 грн.  
   * **Для режиму «Найдешевший»:** мінімізуємо суму basePrice усіх квитків у маршруті.  
> 4. **Як знайти Топ-3 маршрути (узагальнення до *K* найкоротших шляхів):** Замість того, щоб зупиняти алгоритм, коли кінцеву станцію витягнули з PriorityQueue перший раз, ми дозволяємо кожній вершині бути відвіданою до *K*\=3 разів. У чергу з пріоритетом ми кладемо об'єкт PathState (список уже пройдених квитків, поточна станція, поточний час, сумарна вартість). Коли кінцева станція дістається з черги 1-й, 2-й і 3-й раз (за умови, що маршрути не містять циклів), ми отримуємо рівно **Топ-3 найкращі маршрути**.

#### **Жадібний розподіл знижок (Після знаходження Топ-3)**

Нехай маршрут складається з *N* квитків (де *N* — кількість сегментів, тобто *N*−1 пересадка), а у користувача є масив доступних знижок: **Сертифікат (-200 грн)** та **Промокод (-10%)**. Правило: *1 квиток \= максимум 1 знижка*.

> * **Крок 1 (Математика економії):** Для кожного квитка з ціною *Pi*​ рахуємо реальну вигоду від кожної знижки:  
  * Економія від сертифіката: Δcert​(*Pi*​)=min(*Pi*​,200) (бо ціна не може стати меншою за 0 грн).  
  * Економія від промокоду: Δpromo​(*Pi*​)=0.10×*Pi*​.  
> * **Крок 2 (Жадібний вибір):** Оскільки сертифікат дає фіксовані 200 грн (якщо квиток ≥200 грн), а промокод росте лінійно від ціни, промокод найвигідніше кидати на **найдорожчий** квиток у маршруті, але тільки якщо цей квиток не єдиний, який дорожчий за 200 грн. Тому для маршруту з *N*≤4 квитків жадібний алгоритм (або повний перебір пар призначення за *O*(*N*2), що для *N*\=3 це всього 6 операцій\!) миттєво знаходить комбінацію з максимальною сумарною економією max(Δcert​(*Pi*​)+Δpromo​(*Pj*​)) при *i*\=*j*.  
> * **Крок 3 (Фінальний вибір):** Застосовуємо цей розрахунок до кожного з Топ-3 маршрутів і підсвічуємо користувачу той, де **фінальна ціна після знижок найменша** (це і є виконання пункту 4 — *«формування персонального плану з метою зниження ціни на проїзд»*).

### **3\. Parcelable vs JSON vs .txt: що це і як їх поєднати**

У тебе в голові виникла невеличка плутанина між цими трьома поняттями, тому що вони вирішують **різні задачі** на різних етапах роботи програми. Давай розведемо їх по місцях:

| Технологія | Для чого використовується | Де буде у твоєму проєкті |
| :---- | :---- | :---- |
| **Parcelable** | Суто внутрішній механізм Android для надшвидкої передачі об'єкта в оперативній пам'яті **між двома екранами (Activity / Fragment)**. На комп'ютер чи в файл його записати не можна. | Коли користувач клікає на знайдений маршрут або квиток у списку, ти передаєш об'єкт TravelTicket через Intent.putExtra("ticket", ticket) на екран деталей або в діалог редагування. |
| **Firebase (Firestore)** | Хмарна NoSQL база даних (під капотом зберігає документи, схожі на JSON). | Головне сховище в інтернеті. Твій TicketRepository автоматично перетворює об'єкти Java у документи Firestore і навпаки. |
| **Файли .txt (Ввід / Вивід)** | Локальні текстові файли у пам'яті телефона для виконання вимоги методички про **заміну операторів \<\< та \>\>** і розділ «Структура файлу вхідних даних». | Імпорт/експорт розкладу, списку квитків та сертифікатів через екран Налаштувань або кнопку на панелі інструментів. |

#### **Як круто реалізувати ввід/вивід у .txt (заміна \<\< та \>\>):**

Оскільки ти обрав класичний .txt, зробимо структурований текстовий формат із роздільником ; (або по рядках, як у прикладі курсової Морозова). У класі TravelTicket створимо два методи, які на захисті ти прямо назвеш **«об'єктно-орієнтованим еквівалентом операторів потокового виводу \<\< та вводу \>\> у мові Java»**:

> * public void writeToStream(BufferedWriter writer) — записує поля квитка у текстовий потік (аналог operator \<\<).  
> * public static TravelTicket readFromStream(BufferedReader reader) — зчитує рядок з потоку, парсить його, перевіряє на помилки (кидає твій кастомний InvalidTicketDataException, якщо формат битий\!) і повертає готовий об'єкт (аналог operator \>\>).

А твоя ідея про **експорт відфільтрованого та відсортованого списку у .txt файл** — просто топ\! Це ідеально ляже в «Протокол роботи програми»:

> 1. Відсортував квитки через MergeSort.  
> 2. Відфільтрував по місту «Львів».  
> 3. Натиснув «Експортувати поточний список у файл» — і отримав готовий .txt звіт тільки з потрібними квитками.

### **Частина 2\. Реалізація модифікованого алгоритму Дейкстри (Топ-3 маршрути \+ Жадібні знижки)**

Нижче наведено повний клас RoutePlanner, який вирішує **Пункт 4 («Формування персонального плану з метою зниження ціни на проїзд»)**.

#### **Як це працює в коді покроково:**

> 1. Будується список суміжності графа Map\<String, List\<TravelTicket\>\>, де ключ — це місто відправлення, а значення — всі рейси з цього міста.  
> 2. Запускається пошук у черзі з пріоритетом (PriorityQueue\<PathNode\>). Кожен елемент черги зберігає весь пройдений шлях (List\<TravelTicket\>), поточне місто, час прибуття на поточну станцію та накопичену вагу (час або вартість).  
> 3. Перевіряється умова пересадки: ticket.getDepartureTimeMinutes() \>= currentArrivalTime \+ MIN\_TRANSFER\_TIME (15 хвилин).  
> 4. Коли ми дістаємо з черги кінцеве місто (destinationCity), ми не зупиняємо алгоритм одразу, а додаємо знайдений маршрут у список topRoutes, доки не назбираємо **Топ-3 маршрути** (або доки не спустошиться черга).  
> 5. До кожного зі знайдених Топ-3 маршрутів застосовується метод **applyGreedyDiscounts()**, який розподіляє наявні у користувача сертифікати (-200 грн) та промокоди (-10%) між квитками маршруту (за правилом: **1 квиток \= максимум 1 знижка**), максимізуючи сумарну економію.

package com.navrotskyi.trainmanager.domain;

import java.util.\*;

public class RoutePlanner {

    // Мінімальний час на пересадку між потягами (15 хвилин)  
    private static final int MIN\_TRANSFER\_MINUTES \= 15;  
    // Максимальна кількість пересадок (щоб уникати нескінченних або абсурдних маршрутів)  
    private static final int MAX\_SEGMENTS \= 4;

    public enum OptimizationMode {  
        FASTEST,  // Найкоротший за часом (також ідеально для пільговиків на електричках)  
        CHEAPEST  // Найдешевший (Персональний план зниження ціни)  
    }

    // Результат — сформований Персональний план поїздки  
    public static class PersonalTravelPlan {  
        private final List\<TravelTicket\> segments; // Квитки, що входять у маршрут  
        private final Map\<TravelTicket, BonusDiscountStrategy\> appliedDiscounts; // Яка знижка на який квиток пішла  
        private final double baseTotalCost;        // Ціна до застосування промокодів/сертифікатів  
        private final double finalDiscountedCost;  // Фінальна ціна плану після знижок  
        private final long totalDurationMinutes;   // Загальний час у дорозі з урахуванням пересадок

        public PersonalTravelPlan(List\<TravelTicket\> segments,  
                                  Map\<TravelTicket, BonusDiscountStrategy\> appliedDiscounts,  
                                  double baseTotalCost,  
                                  double finalDiscountedCost,  
                                  long totalDurationMinutes) {  
            this.segments \= segments;  
            this.appliedDiscounts \= appliedDiscounts;  
            this.baseTotalCost \= baseTotalCost;  
            this.finalDiscountedCost \= finalDiscountedCost;  
            this.totalDurationMinutes \= totalDurationMinutes;  
        }

        public List\<TravelTicket\> getSegments() { return segments; }  
        public Map\<TravelTicket, BonusDiscountStrategy\> getAppliedDiscounts() { return appliedDiscounts; }  
        public double getBaseTotalCost() { return baseTotalCost; }  
        public double getFinalDiscountedCost() { return finalDiscountedCost; }  
        public double getTotalSaved() { return baseTotalCost \- finalDiscountedCost; }  
        public long getTotalDurationMinutes() { return totalDurationMinutes; }  
    }

    // Внутрішній стан для черги з пріоритетом у алгоритмі Дейкстри  
    private static class PathNode implements Comparable\<PathNode\> {  
        String currentCity;  
        long currentTimeMinutes;  
        long firstDepartureMinutes;  
        double accumulatedCost;  
        double priorityWeight; // Критерій, за яким сортує PriorityQueue  
        List\<TravelTicket\> pathTickets;  
        Set\<String\> visitedCities; // Захист від циклів (щоб не їхати Львів \-\> Київ \-\> Львів)

        PathNode(String currentCity, long currentTimeMinutes, long firstDepartureMinutes,  
                 double accumulatedCost, double priorityWeight,  
                 List\<TravelTicket\> pathTickets, Set\<String\> visitedCities) {  
            this.currentCity \= currentCity;  
            this.currentTimeMinutes \= currentTimeMinutes;  
            this.firstDepartureMinutes \= firstDepartureMinutes;  
            this.accumulatedCost \= accumulatedCost;  
            this.priorityWeight \= priorityWeight;  
            this.pathTickets \= pathTickets;  
            this.visitedCities \= visitedCities;  
        }

        @Override  
        public int compareTo(PathNode other) {  
            return Double.compare(this.priorityWeight, other.priorityWeight);  
        }  
    }

    /\*\*  
     \* Головний метод пошуку Топ-K (за замовчуванням Топ-3) маршрутів  
     \* модифікованим алгоритмом Дейкстри з подальшим жадібним розподілом знижок.  
     \*/  
    public List\<PersonalTravelPlan\> findOptimalPlans(  
            List\<TravelTicket\> allAvailableTickets,  
            String startCity,  
            String endCity,  
            long earliestDepartureTime,  
            CitizenCategory userCategory,  
            List\<BonusDiscountStrategy\> userBonuses,  
            OptimizationMode mode,  
            int topK) throws RouteNotFoundException {

        // 1\. Будуємо граф (список суміжності: Місто \-\> Список рейсів з нього)  
        Map\<String, List\<TravelTicket\>\> graph \= new HashMap\<\>();  
        for (TravelTicket ticket : allAvailableTickets) {  
            graph.computeIfAbsent(ticket.getDepartureCity(), k \-\> new ArrayList\<\>()).add(ticket);  
        }

        // 2\. Черга з пріоритетом для модифікованого Дейкстри  
        PriorityQueue\<PathNode\> pq \= new PriorityQueue\<\>();  
        // Лічильник кількості досягнень кожної станції (дозволяємо до topK разів для пошуку альтернатив)  
        Map\<String, Integer\> visitsCount \= new HashMap\<\>();

        Set\<String\> initialVisited \= new HashSet\<\>();  
        initialVisited.add(startCity);

        pq.add(new PathNode(startCity, earliestDepartureTime, \-1, 0.0, 0.0, new ArrayList\<\>(), initialVisited));

        List\<PathNode\> rawTopRoutes \= new ArrayList\<\>();

        // 3\. Цикл модифікованого алгоритму Дейкстри  
        while (\!pq.isEmpty() && rawTopRoutes.size() \< topK) {  
            PathNode current \= pq.poll();

            // Якщо ми дісталися пункту призначення — зберігаємо маршрут\!  
            if (current.currentCity.equalsIgnoreCase(endCity)) {  
                if (\!current.pathTickets.isEmpty()) {  
                    rawTopRoutes.add(current);  
                }  
                continue;  
            }

            // Обмежуємо кількість відвідувань проміжного вузла, щоб не роздувати чергу  
            int count \= visitsCount.getOrDefault(current.currentCity, 0);  
            if (count \>= topK \* 3\) {  
                continue;  
            }  
            visitsCount.put(current.currentCity, count \+ 1);

            // Обмеження на максимальну кількість пересадок  
            if (current.pathTickets.size() \>= MAX\_SEGMENTS) {  
                continue;  
            }

            // Перебираємо всі сусідні ребра (рейси з поточного міста)  
            List\<TravelTicket\> outgoingTickets \= graph.getOrDefault(current.currentCity, Collections.emptyList());  
            for (TravelTicket edge : outgoingTickets) {  
                String nextCity \= edge.getDestinationCity();

                // Перевірка 1: Не повертаємось у вже пройдене місто (без циклів)  
                if (current.visitedCities.contains(nextCity)) {  
                    continue;  
                }

                // Перевірка 2: Часове вікно (для першого потяга — просто не раніше earliestDepartureTime,  
                // для пересадок — час прибуття попереднього \+ 15 хв на пересадку)  
                long requiredDeparture \= current.pathTickets.isEmpty()  
                        ? current.currentTimeMinutes  
                        : current.currentTimeMinutes \+ MIN\_TRANSFER\_MINUTES;

                if (edge.getDepartureTimeMinutes() \< requiredDeparture) {  
                    continue; // На цей потяг ми не встигаємо\!  
                }

                // Рахуємо вартість квитка з урахуванням категорії громадянина (для пільговика електричка \= 0 грн)  
                double segmentCost \= edge.calculateCategoryPrice(userCategory);  
                double newAccumulatedCost \= current.accumulatedCost \+ segmentCost;

                long newFirstDeparture \= current.pathTickets.isEmpty()  
                        ? edge.getDepartureTimeMinutes()  
                        : current.firstDepartureMinutes;  
                long newArrivalTime \= edge.getArrivalTimeMinutes();  
                long totalElapsedTime \= newArrivalTime \- newFirstDeparture;

                // Визначаємо вагу для PriorityQueue залежно від обраного режиму  
                double newPriorityWeight;  
                if (mode \== OptimizationMode.FASTEST) {  
                    // Мінімізуємо час у дорозі (при рівному часі беремо дешевший)  
                    newPriorityWeight \= totalElapsedTime \+ (newAccumulatedCost \* 0.001);  
                } else {  
                    // Мінімізуємо ціну (при рівній ціні — напр., 0 грн для пільговиків — беремо швидший\!)  
                    newPriorityWeight \= newAccumulatedCost \+ (totalElapsedTime \* 0.001);  
                }

                // Формуємо новий стан шляху  
                List\<TravelTicket\> nextPath \= new ArrayList\<\>(current.pathTickets);  
                nextPath.add(edge);

                Set\<String\> nextVisited \= new HashSet\<\>(current.visitedCities);  
                nextVisited.add(nextCity);

                pq.add(new PathNode(nextCity, newArrivalTime, newFirstDeparture,  
                        newAccumulatedCost, newPriorityWeight, nextPath, nextVisited));  
            }  
        }

        // Якщо жодного маршруту не знайдено — кидаємо наш кастомний виняток (для звіту\!)  
        if (rawTopRoutes.isEmpty()) {  
            throw new RouteNotFoundException("Маршрут між '" \+ startCity \+ "' та '" \+ endCity \+ "' у заданий час не знайдено\!");  
        }

        // 4\. Застосовуємо жадібний розподіл знижок (сертифікат \-200 грн, промокод \-10%) до Топ-3 маршрутів  
        List\<PersonalTravelPlan\> finalPlans \= new ArrayList\<\>();  
        for (PathNode routeNode : rawTopRoutes) {  
            PersonalTravelPlan plan \= applyGreedyDiscounts(routeNode, userCategory, userBonuses);  
            finalPlans.add(plan);  
        }

        // Якщо користувач обрав режим "Найдешевший (Персональний план)", додатково сортуємо Топ-3  
        // за фінальною ціною ПІСЛЯ застосування сертифікатів та промокодів\!  
        if (mode \== OptimizationMode.CHEAPEST) {  
            finalPlans.sort(Comparator.comparingDouble(PersonalTravelPlan::getFinalDiscountedCost)  
                    .thenComparingLong(PersonalTravelPlan::getTotalDurationMinutes));  
        }

        return finalPlans;  
    }

    /\*\*  
     \* Жадібний алгоритм розподілу бонусних знижок (1 квиток \= максимум 1 бонусна знижка).  
     \* На кожному кроці шукає пару (Квиток \+ Бонус), яка дає найбільшу економію в гривнях.  
     \*/  
    private PersonalTravelPlan applyGreedyDiscounts(  
            PathNode routeNode,  
            CitizenCategory userCategory,  
            List\<BonusDiscountStrategy\> availableBonuses) {

        List\<TravelTicket\> segments \= routeNode.pathTickets;  
        Map\<TravelTicket, BonusDiscountStrategy\> assignedDiscounts \= new HashMap\<\>();

        if (availableBonuses \!= null && \!availableBonuses.isEmpty()) {  
            Set\<Integer\> usedTicketIndices \= new HashSet\<\>();  
            Set\<Integer\> usedBonusIndices \= new HashSet\<\>();

            // Кількість кроків жадібного вибору \= min(кількість квитків у маршруті, кількість бонусів)  
            int maxAssignments \= Math.min(segments.size(), availableBonuses.size());

            for (int step \= 0; step \< maxAssignments; step++) {  
                double bestSavings \= 0.0;  
                int bestTicketIdx \= \-1;  
                int bestBonusIdx \= \-1;

                // Шукаємо пару (невикористаний квиток, невикористаний бонус) з максимальною економією  
                for (int t \= 0; t \< segments.size(); t++) {  
                    if (usedTicketIndices.contains(t)) continue;

                    double ticketPrice \= segments.get(t).calculateCategoryPrice(userCategory);  
                    if (ticketPrice \<= 0\) continue; // На безкоштовний пільговий квиток знижку не витрачаємо\!

                    for (int b \= 0; b \< availableBonuses.size(); b++) {  
                        if (usedBonusIndices.contains(b)) continue;

                        double savings \= availableBonuses.get(b).calculateSavings(ticketPrice);  
                        if (savings \> bestSavings) {  
                            bestSavings \= savings;  
                            bestTicketIdx \= t;  
                            bestBonusIdx \= b;  
                        }  
                    }  
                }

                // Якщо знайшли вигідну комбінацію — фіксуємо її  
                if (bestTicketIdx \!= \-1 && bestBonusIdx \!= \-1 && bestSavings \> 0\) {  
                    usedTicketIndices.add(bestTicketIdx);  
                    usedBonusIndices.add(bestBonusIdx);  
                    assignedDiscounts.put(segments.get(bestTicketIdx), availableBonuses.get(bestBonusIdx));  
                } else {  
                    break; // Більше економити ніде  
                }  
            }  
        }

        // Підраховуємо підсумкову вартість після застосування всіх призначених знижок  
        double totalSavings \= 0.0;  
        for (Map.Entry\<TravelTicket, BonusDiscountStrategy\> entry : assignedDiscounts.entrySet()) {  
            double price \= entry.getKey().calculateCategoryPrice(userCategory);  
            totalSavings \+= entry.getValue().calculateSavings(price);  
        }

        double baseCost \= routeNode.accumulatedCost;  
        double finalCost \= Math.max(0.0, baseCost \- totalSavings);  
        long totalDuration \= routeNode.currentTimeMinutes \- routeNode.firstDepartureMinutes;

        return new PersonalTravelPlan(segments, assignedDiscounts, baseCost, finalCost, totalDuration);  
    }  
}

### **Чому ця реалізація ідеально захистить тебе на здачі:**

> 1. **Елегантна прив'язка для пільговиків:** Подивись на рядок newPriorityWeight \= newAccumulatedCost \+ (totalElapsedTime \* 0.001);. Якщо користувач — **Пільговик**, то для всіх приміських електричок newAccumulatedCost дорівнює 0.0 грн. Завдяки маленькому коефіцієнту 0.001 \* totalElapsedTime, алгоритм Дейкстри серед усіх безкоштовних електричок автоматично вибере **найшвидшу за часом**, навіть у режимі пошуку найдешевшого маршруту\!  
> 2. **Чесний жадібний алгоритм без зайвих витрат:** Якщо у маршруті 2 пересадки, де один квиток — безкоштовна електричка (0 грн), а другий — Інтерсіті (600 грн), перевірка if (ticketPrice \<= 0\) continue; гарантує, що сертифікат чи промокод ніколи не «згорить» на безкоштовному квитку.  
> 3. **Готові винятки:** Клас кидає RouteNotFoundException, якщо граф не має шляху або пасажир не встигає на пересадку — це вже 1 із 3 обов'язкових try-catch сценаріїв для звіту.
